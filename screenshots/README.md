# Cloud-Based Static Website Deployment

## Project Overview
This project demonstrates the deployment of a static website using cloud services.

## Technologies Used
- HTML
- CSS
- JavaScript
- AWS S3

## Project Features
- Responsive static website
- HTML, CSS and JavaScript
- Cloud-based hosting
- Public website deployment

## Project Structure
- index.html - Main webpage
- style.css - Website styling
- script.js - JavaScript functionality
- screenshots/ - Project screenshots

## Deployment
The static website is deployed using Amazon S3 Static Website Hosting.
